# Sound Files

Place your MP3 sound files in this directory. They will be used by the focus application.

## Required files:

1. **session-complete.mp3** - Sound to play when a focus session completes
   - Recommended: Success/ding sound (1-2 seconds)
   - Example: Ascending bell tones, success chime

2. **break-end.mp3** - Sound to play when a break ends  
   - Recommended: Alert/notification sound (1-2 seconds)
   - Example: Alert chime, gentle reminder tone

3. **notification.mp3** - Sound to play for notifications
   - Recommended: Gentle notification sound (0.5-1.5 seconds)
   - Example: Subtle ping, soft bell

## Optional:

The application has built-in Web Audio API sounds as fallback. If these files are not present, the app will use synthesized beep tones automatically.

## How to add sounds:

1. Find or create your sound files as MP3 format
2. Place them in this directory with the exact filenames above
3. No additional configuration needed - the app will detect and use them
