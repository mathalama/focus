## 🎯 Как это работает

### SessionPage
1. Когда время фокус-сессии истекает (`timeLeft === 0`):
   - Если включены звуки → проигрывается успешный аккорд
   - Отправляется браузерное уведомление
   
2. Когда закончивается перерыв:
   - Если включены звуки → проигрывается двухтонный сигнал
   - Отправляется уведомление о окончании перерыва

### ProfilePage
- **Sounds toggle**: Сохраняет в `localStorage.sounds-enabled`
- **Notifications toggle**: Запрашивает разрешение браузера и проверяет статус

## 🔧 Интеграция звуков MP3 (опционально)

Если хотите собственные звуки вместо синтезированных:

1. Подготовьте MP3 файлы (1-2 секунды каждый)
2. Разместите в `frontend/public/sounds/`:
   - `session-complete.mp3`
   - `break-end.mp3`
   - `notification.mp3`
3. Приложение автоматически обнаружит и использует их

**Рекомендуемые источники:**
- Freesound.org
- Zapsplat.com
- Notification Sounds (Google Play)

## 📝 API и функции

### Звуки
```typescript
import { playSound, playSuccessMelody, playBeep } from '@/lib/sounds'

// Проиграть звук по типу
await playSound('session-complete', 0.7)

// Проиграть успешный мелодический аккорд
playSuccessMelody()

// Проиграть простой beep (frequency, duration, volume)
playBeep(800, 200, 0.3)
```

### Уведомления
```typescript
import { showNotification, requestNotificationPermission, notificationsEnabled } from '@/lib/notifications'

// Запросить разрешение
const granted = await requestNotificationPermission()

// Проверить статус
const enabled = notificationsEnabled()

// Показать уведомление
await showNotification({
  title: 'Готово!',
  body: 'Сессия завершена',
  tag: 'session-complete'
})
```
