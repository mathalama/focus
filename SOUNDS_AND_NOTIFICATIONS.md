# Звуки и уведомления в Mathalama Focus

Приложение поддерживает звуковые оповещения и браузерные push-уведомления для отслеживания фокус-сессий.

## 🔊 Звуки

### Когда срабатывают?
- **Session Complete (Сессия завершена)**: Проигрывается успешный трёхтонный аккорд при завершении фокус-сессии
- **Break End (Перерыв окончился)**: Проигрывается уведомляющий двухтонный сигнал при завершении перерыва

### Управление звуками
1. Перейдите на страницу **Профиля** (вкладка Profile)
2. Найдите секцию **"Звуки"**
3. Нажмите на переключатель **Включены/Отключены**
4. Звуки сохранятся в localStorage браузера

### Пользовательские звуки (MP3)
Если вы хотите использовать собственные звуки вместо синтезированных:

1. Подготовьте MP3 файлы:
   - `session-complete.mp3` - для завершения сессии
   - `break-end.mp3` - для завершения перерыва
   - `notification.mp3` - для общих уведомлений

2. Поместите их в `frontend/public/sounds/`

3. Приложение автоматически обнаружит и использует их

Если файлы отсутствуют, приложение будет использовать синтезированные звуки (встроенные beeps с Web Audio API).

## 🔔 Push-уведомления браузера

### Когда срабатывают?
- **После завершения сессии**: "🎉 Сессия завершена! Отлично поработали! Время для отражения."
- **После завершения перерыва**: "⏰ Перерыв закончился. Готовы продолжить?"

### Как включить?
1. Откройте страницу **Профиля**
2. Найдите секцию **"Уведомления"**
3. Нажмите на переключатель - браузер запросит разрешение
4. Разрешите уведомления

### Преимущества
- Уведомления видны даже если вкладка неактивна
- Автоматически закрываются через 5 секунд
- Можно кликнуть на уведомление, и оно вернёт вас в окно приложения

### Требования
- Современный браузер с поддержкой Web API (Chrome, Firefox, Safari, Edge)
- Разрешение от пользователя на отправку уведомлений

## 📱 Техническая реализация

### Файлы
- `src/lib/sounds.ts` - управление звуками и Web Audio API
- `src/lib/notifications.ts` - управление браузерными уведомлениями
- `src/pages/SessionPage.tsx` - интеграция звуков и уведомлений в сессию
- `src/pages/ProfilePage.tsx` - UI для управления параметрами

### Функции

#### Звуки
```typescript
// Воспроизвести звук по типу
playSound('session-complete', 0.7)

// Проиграть успешный мелодический аккорд
playSuccessMelody()

// Проиграть простой beep (частота, длительность, громкость)
playBeep(800, 200, 0.3)
```

#### Уведомления
```typescript
// Запросить разрешение
await requestNotificationPermission()

// Проверить включены ли уведомления
notificationsEnabled()

// Показать уведомление
await showNotification({
  title: 'Заголовок',
  body: 'Тело уведомления',
  tag: 'unique-id'
})

// Специальные уведомления
await notifySessionComplete()
await notifyBreakEnd()
```

## 🎵 Как работает Web Audio API

Если MP3 файлы недоступны, приложение синтезирует звуки используя Web Audio API:

1. **Success Melody** (Завершение сессии):
   - 3 восходящих тона (523Hz → 659Hz → 783Hz)
   - Каждый по 200ms с интервалом 150ms

2. **Break End Alert**:
   - 2 тона (600Hz, 800Hz)
   - По 300ms каждый

3. **Single Beep**:
   - Настраиваемая частота, длительность и громкость

## 🔒 Безопасность и конфиденциальность

- Все данные о звуках/уведомлениях хранятся локально в localStorage
- Браузерные уведомления контролируются операционной системой
- Ничего не отправляется на серверы без вашего согласия
